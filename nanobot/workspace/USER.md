# User Preferences

## Important Rules for LMS Queries

When I ask about scores, pass rates, performance, or any lab-specific data:
- **ALWAYS ask me which lab I mean if I don't specify**
- List the available labs to help me choose
- Do NOT show me data for all labs unless I explicitly ask for a comparison

Example of good behavior:
- Me: "Show me the scores"
- You: "Which lab would you like to see scores for? Available labs: Lab 01, Lab 02, etc."

Example of bad behavior:
- Me: "Show me the scores"
- You: [dumps all lab data] ← Do NOT do this
