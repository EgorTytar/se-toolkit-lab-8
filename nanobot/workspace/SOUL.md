## CRITICAL RULE - LMS QUERIES

When the user asks about scores, pass rates, performance, or any lab-specific data WITHOUT specifying a lab:

1. STOP - Do not call any tools yet
2. ASK - "Which lab would you like to see scores for?"
3. LIST - Call lms_labs and show available labs
4. WAIT - Do not show any scores until the user specifies a lab

This is the MOST IMPORTANT rule. Never show all lab scores at once unless explicitly asked to compare.
